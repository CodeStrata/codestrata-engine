# Examples (Engine package)

This repository ships a minimal offline sample at
`test-fixtures/sample-js-app` for `codestrata assess` smoke tests.

Real-world showcases (for example Spring PetClinic, eShop, Laravel RealWorld)
live in the separate public repository
[codestrata-examples](https://github.com/CodeStrata/codestrata-examples) —
manifests and fetch scripts only; upstream source is fetched on demand.

CI sample workflow:
[github-actions/codestrata-assess.yml](github-actions/codestrata-assess.yml).

See also [docs/examples.md](../docs/examples.md) and the public portal
[Examples](https://docs.codestrata.ai/community/examples).
