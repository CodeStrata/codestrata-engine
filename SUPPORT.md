# Support

Thanks for using **CodeStrata Community Edition**.

## How to get help

1. Read [docs/quick-start.md](docs/quick-start.md) and
   [docs/troubleshooting.md](docs/troubleshooting.md).
2. Search [existing GitHub Issues](https://github.com/CodeStrata/codestrata-engine/issues).
3. Open a new issue with:
   * `codestrata version` output
   * The exact command you ran (sanitize secrets)
   * Expected vs actual behavior

## Security vulnerabilities

Do **not** file public issues for security problems. Follow
[SECURITY.md](SECURITY.md).

## Community guidelines

Please follow the [Code of Conduct](CODE_OF_CONDUCT.md) in all interactions.

## Commercial / Enterprise inquiries

Hosted Platform, portfolio governance, and Enterprise services are **not** part
of Community Edition. See [docs/community-edition.md](docs/community-edition.md)
for boundaries. For commercial questions, contact the maintainer via the GitHub
profile linked from the repository.
