## Step 1 — Close R01 (monorepo + PyPI)

1. **Merge** `.github/workflows/engine-pypi-release.yml` to the branch used for release (admin review; outside `engine/` scope).
2. In GitHub: **Settings → Environments → `engine-pypi`** (or create it) with required reviewers.
3. On [pypi.org](https://pypi.org): **Publishing → Add a new pending publisher**  
   - Owner: `CodeStrata`  
   - Repository: `codestrata-platform`  
   - Workflow: `engine-pypi-release.yml`  
   - Environment: `engine-pypi` (if used)
4. Verify inventory locally:

   ```bash
   cd engine
   python -c "from pathlib import Path; from verification.live_release_baseline.publisher import evaluate_r01; from verification.live_release_baseline.workflows import load_root_workflows; i=evaluate_r01(load_root_workflows(Path('..'))); print(i.status.value, i.engine_only_oidc_publisher)"
   ```

   Expect: `PRESENT .github/workflows/engine-pypi-release.yml`

5. Update `baseline.md` R01 status to **PRESENT** with date and workflow path.

## Step 2 — Release-owner authorization (before upload)

2. Bump to **0.2.2** in `engine/pyproject.toml`, `src/codestrata/__init__.py`, and `CHANGELOG.md`.
3. Run:

   ```bash
   cd engine
   ```

## Step 3 — Publish (authorized human)

2. GitHub → **Actions → engine-pypi-release → Run workflow**  
   - Input `confirm_release`: `PUBLISH`
3. **Do not** bulk-update mirrors, force customer upgrades, or deploy hosted product.
