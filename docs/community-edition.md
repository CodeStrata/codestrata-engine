# Community Edition

<!-- documentation-visibility: public-community -->

> **Canonical public page:** [Community vs Platform](https://docs.codestrata.ai/community/vs-platform)

CodeStrata **Community Edition** is the open-source, MIT-licensed Engine you
install for assessing **one repository at a time** on a local machine.

Advanced portfolio and organizational capabilities are available in
**CodeStrata Platform**. They are not required for Community assess.

## Principle

> Community helps teams understand and improve software.  
> Platform helps organizations persist, connect, and reason across repositories.

## Included in Community Edition

| Area | Status |
| ---- | ------ |
| Local / GitHub repository scan & assess | Included |
| Technology detection (Java, JS/TS, Python, PHP, C#/.NET) | Included |
| Dependency evidence (Maven, npm, Composer, NuGet) | Included |
| Deterministic rules → findings → recommendations | Included |
| HTML + JSON assessment reports | Included |
| Optional one-call AI enrichment (developer-configured providers) | Included (optional) |
| Local knowledge store (deterministic) | Included |
| Local MCP server | Included (optional `mcp` extra) |
| Agent Framework (local orchestration) | Included |
| Incremental assessment (opt-in) | Included |
