## Current verified depth (inspected, not claimed as already deepest)

E05.1 pins: all five language providers are PARTIAL structurally. Java
complexity is brace-aware regex, not javac. JS/TS has **no** complexity
extractor. Python complexity uses the stdlib AST. Launch deepest-path work
for Java/JS/TS is still due in later stories; this file does not promote
Python/PHP/C# to that target.

## What this story does not do

It does not implement analyzers, YAML rules, feed download, Git indexing or
severity-calibrator deletion. `application/findings/severity_calibration.py`
still exists; E01.2/E04 must bind context caps into the versioned default and
stop post-override rewrites.
