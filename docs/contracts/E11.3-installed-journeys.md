# E11.3 installed journeys

Run these checks on a wheel installed outside the source checkout. Leave
`PYTHONPATH` unset. The sample repositories live under `examples/journeys/`
and are copied into a clean directory. They do not refer to another
product tree or a path outside `examples/journeys/`.

A first `codestrata assess --repo . --no-ai` says `no baseline`. Delta and
outcome movement stay unavailable. The report does not invent a trend, a
healthy badge, or a score.

`canonical-report.html`, `canonical-report.json`, and
`canonical-report.sarif.json` are the same canonical object. HTML links for
findings and evidence use that object's ids. Ranking, deltas, and movement
are copied. They are not calculated in the page.

Missing git history, a shallow repository, a missing vulnerability feed, a
stale feed, an unknown author, a missing test association, and an impact
cutoff stay qualified. A failed vulnerability-feed read keeps that family's
limitation beside the other views. Secret text is redacted in HTML, JSON, and
SARIF.

`codestrata compare --baseline <analysis-result.json> --candidate <analysis-result.json>`
uses explicit paths. Incompatible ruleset majors stay insufficient. A
controlled source fix reports the finding lifecycle from that comparison.
Restarting assess does not create a SQLite database.
