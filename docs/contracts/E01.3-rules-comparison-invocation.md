# E01.3 rules, comparison and neutral invocation

**Package revision:** `ENGINE-2026-09-15-R1`  
**Consumes:** E01.2 envelopes and the E01.1 launch ratification  
**Machine artifacts:** JSON schemas under `engine/schemas/contracts/codestrata.io/v1.2/`  
**Independent reviewer required:** Sangram Gaikwad

E01.3 publishes Engine-owned **Rule**, **RuleSet**, **Effective RuleSet**,
**signed-package manifest**, **comparison envelope** and **headless local job**
schemas. It does not implement the RuleSet resolver (E04) or the YAML compiler
(E03).

## Bound identities

Resolved execution binds `effective_ruleset_digest`, signed package digest,
unsigned local config digest, feed digest, input digest and pinned versions
(`ruleset_version`, `resolver_version`, `dsl_version`, `capability_version`,
`engine_version`). Floating versions (`latest`, `*`) are rejected. Signatures
and operational timestamps stay outside content digests.

## Preview vs production

`execution_purpose` is `production` or `preview` on a signed package.
`candidate_validation` is a separate local purpose. Preview cannot admit
production. `preview_cannot_authorize_production` is always true.

## Comparison

The comparison envelope records compatibility status, reasons, outcome
movement and **cause attribution** (`source_only`, `feed_only`,
`configuration_only`, `mixed`, `undetermined`). A first run is `no_baseline` /
`insufficient`, never Stable. Incompatible comparisons cannot claim Improved or
Stable. Multiple changed source/feed/config dimensions without a controlled
equivalent-input rerun are mixed or undetermined.

## Headless invocation

Invocation accepts local paths, pinned input digests and export/trust
configuration. Platform credentials, hosted URLs and hosted calls are
rejected. Network mode is offline.

Optional PR title/description/base/head/labels/linked-references are bounded,
carry a `context_digest` and provenance, and **do not enter canonical
computation**. Head/SHA disagreement must be disclosed as `conflict`.

## Candidate validation and local jobs

Candidate validation binds candidate/selector/config/input/engine/DSL digests,
permitted local scope, purpose and expiry. Results cannot be promoted to
production; stale preview evidence is rejected.

Local progress, cancellation (grace + process hard cap) and terminal state are
independent of assessment truth. Killed, cancelled or failed jobs cannot expose
a completed assessment digest or a successful completion.
