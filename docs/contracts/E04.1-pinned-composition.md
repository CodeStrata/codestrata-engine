# E04.1 pinned composition and deterministic precedence

**Package revision:** `ENGINE-2026-09-15-R1`  
**Consumes:** E01.3 Rule/RuleSet parse contracts and E01.1 composition budgets  
**Machine artifact:** `engine/schemas/contracts/codestrata.io/v1.2/ComposedRuleSet.json`

E04.1 implements a **pure in-memory/file RuleSet resolver**. It does not apply
typed policy overrides or scoped exceptions (E04.2) and does not seal an
Effective RuleSet digest for execution (E04.3). Release tooling pre-resolves
the bundled Community catalog through:

```text
python -m codestrata.application.rules.composition --bundled --output <dir>
```

Local file catalogs are admitted with `--catalog <dir>`. There is no runtime
fetch, mutable URL, or floating version.

## Pins and rejection

Every parent RuleSet, Rule revision and selector is identified by immutable
id, dotted version and content digest. Missing pins, digest mismatches, cycles,
YAML aliases, path escapes, parent depth above 8 and more than 1,000 effective
rules are rejected. Tokens such as `latest`, `*` and `main` are floating
references.

## Precedence

Parents resolve before the child. In an ordered `extends` list, later parents
override earlier **configuration** (enabled/adoption/parameter maps). Parent
disagreement on a Rule **revision** is not resolved by that order; the child
must pin the chosen revision. Child entries override parents after that pin.

## Merge

Rule maps merge by rule id. Typed parameter maps merge by defined field.
Lists and scalars replace atomically. Omitted fields inherit. JSON `null`
does not reset a parent value. `default_enabled` is mandatory on the composed
result. Adoption remains a label, not an activation switch.

## Selectors

Selector IDs are namespaced. Identical ASTs (canonical `source`+`nodes`)
deduplicate. Conflicting ASTs for the same id cannot shadow. A Rule that
uses `selector_ref` must match the composed selector digest.

## Determinism

Identical catalog bytes and root RuleSet bytes yield identical canonical
composed JSON, including `composition_digest`. Signatures and timestamps are
not part of this artifact.
