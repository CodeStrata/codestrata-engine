# E01.2 descriptors, identities and envelopes

**Package revision:** `ENGINE-2026-09-15-R1`  
**Consumes:** `launch-ratification-v1.yaml` (E01.1)  
**Machine artifacts:** JSON schemas under `engine/schemas/contracts/codestrata.io/v1.2/`  
**Independent reviewer required:** Sangram Gaikwad

E01.2 publishes the shared AnalyzerDescriptor, fact/graph/evidence records,
canonical envelope, identity map, outcome-driver manifest, M22 Engineering
Hotspot schema, scoped M25 records, M27/M29 change-summary fields and
per-capability coverage/freshness. It does not implement analyzers.

## Envelope split

The **body** is the deterministic comparison document: repository-local
subjects, facts, graph, findings, hotspots, ownership, change summary,
coverage, freshness and comparison availability. `evaluation_time` is in the
body only when a time-relative metric needs it.

**Operational metadata** (`run_id`, `generated_at`, `duration_ms`, `signature`)
is outside the body and outside `body_digest`.

Tenant, workspace, portfolio and job identity are forbidden in the analysis
body. Unknown fields and unsupported major versions reject.

## Identity

Existing Repository Graph and finding IDs are kept. File identity is a
normalized relative path. Finding identity is `finding:{rule}:{digest}` from
rule plus subject/occurrence keys; line numbers and message text are not
identity material.

## Severity

Context-derived caps bind only to versioned `default_severity` on the
rule/config contract. After an approved override, `effective_severity` is
frozen; later context classification must not rewrite it. The existing
`severity_calibration.py` helper remains until E04 removes post-override
rewrite from the application path.

## Aggregation

Required scopes and known FAIL findings cannot disappear when a family is
rolled up. Empty or fully disabled driver sets are NOT_APPLICABLE, never
healthy.

## Examples

`engine/tests/contracts/fixtures/e01.2/` holds complete, partial, UNKNOWN and
no-baseline envelopes plus negative payloads.
