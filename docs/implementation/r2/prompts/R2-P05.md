# R2-P05 — First-Parent Selection and Immutable Snapshot Materialization

## Goal
Build safe read-only source-state extraction for committed HEAD + four first-parent predecessors.

## Required work
- resolve committed HEAD;
- select up to five SHAs using first-parent history (`--max-count=5` semantics);
- retain requested five-slot model if fewer commits exist;
- reverse for oldest→newest display;
- materialize each available commit tree into an isolated temporary directory;
- use the existing read-only Git abstraction; minimally expand allowed read-only verbs if required (`archive` or ls-tree/show approach);
- never run `git checkout`, mutate index/worktree, invoke hooks, or execute repository build/tests merely to extract source;
- robust cleanup on success/failure.

## Required tests
- five-commit fixture tree bytes match each SHA;
- dirty uncommitted file never appears in extracted snapshots;
- user status/index/worktree unchanged before vs after;
- fewer than five commits retains missing slots explicitly;
- unsupported/submodule/symlink behavior documented and safe.
