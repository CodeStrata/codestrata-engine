# R2-P10 — Full R2 Acceptance and Release Handoff

## Goal
Qualify R2 implementation and produce evidence needed to enter a fresh G50 on exact artifacts.

## Mandatory matrix
Baseline:
- complete supported repo;
- partial/unsupported capability;
- no Git history;
- shallow Git;
- missing/stale feed;
- dirty working tree;
- graph available/unavailable;
- Architecture Map node/edge parity.

Trend:
- exactly five commits;
- fewer than five;
- dirty user worktree excluded/unchanged;
- failed middle snapshot;
- future-source/history leakage adversarial fixture;
- incompatible comparison;
- M29 cutoff/lower-bound;
- two identical runs with deterministic semantic outputs.

Installed artifacts:
- wheel outside checkout;
- sdist outside checkout;
- container when required by existing G50 contract;
- generated primary baseline + trend HTML and canonical sidecars.

Boundary:
- no Platform import;
- no new OutcomeFamily/analyzer;
- no score;
- custom-rule authoring/loading/import still unsupported Community surface;
- no default DB;
- no AI canonical truth.

## Deliver
A read-only R2-G3 audit on the exact final SHA, including artifact digests and expected/actual values.

Do not publish. A G3 PASS only unlocks a fresh existing G50 qualification and release-owner decision.
