# R2-P07 — Durable Five-Slot Trend Artifact Bundle

## Goal
Persist the five-snapshot run as a deterministic local file bundle without abusing baseline current/previous retention.

## Required content
- series/index metadata;
- requested/observed/missing slots;
- pinned evaluation profile/digests;
- snapshot artifacts per slot;
- comparison directories/placeholders;
- final trend HTML/JSON locations;
- error/UNKNOWN status for failed slots.

Use a dedicated trend namespace under the existing artifact root. Do not rotate five snapshots through `current/previous`.

## Required properties
- stable oldest→newest slot identity;
- evidence remains addressable after the full run;
- no accidental cleanup of earlier series slot while later slot runs;
- explicit retention policy;
- file-only, no DB;
- deterministic index ordering and canonical IDs.

## Tests
- five available slots;
- fewer than five;
- middle assessment failure;
- rerun behavior;
- path safety/cleanup;
- no collision with baseline artifact lifecycle.

Return evidence and stop.
