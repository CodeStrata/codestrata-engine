# R2-P09 — Five-Commit Engineering Health Trend HTML

## Goal
Deliver a single offline trend report aligned with `reference/five-commit-trend-report.html`.

## Required views
- current committed HEAD four-outcome Engineering Health;
- five source-state observations, oldest→newest;
- selector for four adjacent + one span comparison;
- per-outcome M30 movement;
- M28 lifecycle;
- M27 changed scope;
- M29 static impact/blast radius;
- supplied Before/After/Delta named metrics;
- M31 cause/reason;
- current hotspots/ownership/co-change;
- source-state-bound evidence appendix.

## Rendering rules
- no composite score;
- no HTML subtraction/ranking/lifecycle inference;
- missing snapshot remains visible;
- incompatible metric remains a gap with reason;
- equal finding count does not imply Stable;
- every evidence link resolves to originating snapshot/commit;
- offline/no CDN;
- Architecture/impact visualizations use canonical graph/comparison records only.

## Validation
Generate from real Engine five-commit fixture and at least one nontrivial real repository. Compare displayed values with canonical JSON. Visual review required.

After completion STOP. R2-G2 must pass before P10.
