## PR text for `release/engine-next`

```text
E14.1: Add strict public Sigstore and private offline verification profiles

Offline ECDSA P-256 / Ed25519 verification of signed packages with distinct
public-distribution and private-result roles. Public bundles check expected
identity, OIDC issuer, certificate, signature and a digest-only transparency
log. The private profile forbids a public log and treats revocation as a
freshness limit, not instant CRL. Real cryptographic fixtures cover
valid/tampered/wrong-issuer/wrong-purpose/expired/unsupported cases.

Does not publish, tag, or close R01. E14.2/E14.3/E14.4 remain due.
```
