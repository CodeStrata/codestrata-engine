## Limitations

- HTML does not compute ranking, Jaccard, deltas, or outcome movement. Co-change rows and comparison deltas must already be on the canonical inputs. An empty co-change list is shown as unavailable.
- `DriverDelta` has one comparison coverage status, not a separate before/after coverage pair. The delta table prints that status and points at the candidate capability table.
- Assess still writes the existing customer HTML. This module is the canonical three-format projection. Installed-wheel journeys stay E11.3 / G40 / G50, **NOT_YET_DUE**.
- Host `pip-audit` FAIL is the interpreter package, not an Engine dependency change.
