## PR text for `release/engine-next`

Title: `E13.3: Test export restrictions and signed-projection integrity`

Body:

Add explicit full/restricted/no-export modes for headless `telemetry export`, with a withheld-category manifest. No-export keeps local analysis working and performs no collector transfer. Redaction leaves the local original canonical bytes unchanged and emits a separate signed projection that lists the original digest, allowed/withheld categories, export-policy version, and operational signature metadata. A projection cannot claim unseen evidence was externally verified. Fake-collector tests cover revoked and expired receipts; actual server deletion/admission is not claimed. Local HMAC is not public Sigstore.
