## PR text for `release/engine-next`

Title: `E08.1: Define and emit structural quality metrics`

Body:

Emit M16 size/function complexity, M17 maximum nesting depth and M18 token clone indicator from one canonical quality envelope. Cyclomatic v1 is 1 plus the frozen per-language branch map (Java, JS/TS, Python); nloc is nonblank noncomment. There is no language-independent maintainability index. Unparsed or unsupported syntax is UNKNOWN/partial, never a misleading zero. Clone indicator matches exact normalized token runs (>=50 tokens, >=5 lines), merges overlaps, and keeps identifiers so a rename is not a clone. Thresholds are explicit heuristics: complexity >15 medium, function nloc >80 low, nesting >4 medium, clone ratio >0.10 low advisory. YAML catalog is the runtime boundary. No live lookup and no repository execution.
