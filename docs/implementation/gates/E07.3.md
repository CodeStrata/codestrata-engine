## PR text for `release/engine-next`

```text
E07.3: Migrate remaining launch architecture rules and validate depth

Map each retained Python architecture rule to a YAML id and record that the
old and new counts are not equivalent scores. Add
architecture.invalid-dependency-direction and architecture.framework-leakage
to the launch catalog. Direction applies only to an explicit allowed set:
a known violation fails, an unresolved edge is unknown, and a missing set
is not applicable. Framework leakage fails on a structural domain symbol
and stays unknown when the language tier cannot see framework symbols.

Java and JS/TS structural paths are admitted from the language providers.
Python, PHP, and C# stay on the verified retained tier. The comparison
projection copies pass, fail, unknown, and not-applicable outcomes into
JSON, HTML, and SARIF so a later consumer does not recompute the graph.
Enterprise standard mismatch and the deferred service cycle are not migrated.

Does not implement the next group or change the legacy SharedRule pack.
```
