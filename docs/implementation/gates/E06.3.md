## PR text for `release/engine-next`

Title: `E06.3: Complete version hygiene, license evidence and accuracy gate`

Body:

Bind unresolved, mutable, unbounded, conflicting and duplicate dependency declarations to bundled YAML. Add deterministic SPDX license metadata and `license.disallowed` against an explicit configured allow/deny list (default medium); absent policy is metadata only. Missing, malformed, unsupported or conflicting expressions are UNKNOWN and are never guessed allowed or denied. This is not a legal-compliance verdict. Publish M15 confusion counts and precision/recall on a frozen labeled manifest; UNKNOWN is separate; zero denominator is undefined. Published flagship groups meet the proposed bar (precision >=0.95, recall >=0.90, >=20 positive and >=20 negative) with no known critical false-negative and no secret leak. Holdout is scored separately. No live lookup and no package install.
