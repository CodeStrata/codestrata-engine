## PR text for `release/engine-next`

Title: `E04.1: Implement pinned RuleSet composition and deterministic precedence`

Body:

Add a pure in-memory/file RuleSet resolver that pins parents, rule revisions and selectors by version and content digest. Reject missing, cyclic and floating references, YAML aliases, path escapes, and composition beyond the ratified parent-depth and effective-rule budgets. Later ordered parents override earlier configuration; parent revision conflicts require an explicit child pin. Parameter maps merge by defined fields; lists and scalars replace; omitted fields inherit; null does not reset. Conflicting selector ASTs cannot shadow. Identical catalog bytes resolve to identical canonical composed JSON. Ship `python -m codestrata.application.rules.composition` for release-time pre-resolution of the bundled Community catalog. Policy overrides and Effective RuleSet sealing remain later stories.

Reviewer: Sangram Gaikwad. Do not self-merge.
