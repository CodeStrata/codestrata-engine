## PR text for `release/engine-next`

Title: `E02.3: Narrow Community surfaces; keep safe compatibility`

Body:

Remove portfolio/EIR lifecycle, hosted Platform ingest, and Community Cloud
report upload from Community execution. Canonical `platform_client_from_settings`
always returns `OfflinePlatformClient`; publishers return `removed` without
HTTP. `codestrata report publish` is deprecated. Customer rule CLI/MCP tools
remain read-only inspect. SQLite is not a production package export; leftover
`knowledge.sqlite` can be dumped only via
`python -m codestrata.infrastructure.knowledge_store.sqlite.export`. Existing
intelligence trees, SQLite files, and prior installs are left untouched.
`RestPlatformClient` stays importable for outside-Engine hosts.
