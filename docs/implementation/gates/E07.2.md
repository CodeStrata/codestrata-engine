## Limitations

- Working tree is uncommitted; candidate SHA is the `92482fb6` base plus this diff.
- The disallow pattern is the declared constraint. `allowed_directions` is explicit run configuration and is part of the digest; it does not invent additional forbids.
- A local pattern that differs from the bundled YAML defaults is effective configuration. The rule plan digest stays the bundled rule; the launch `facts_digest` carries the effective pattern.
- A selector digest that does not match the compiled rule is `selector_rebinding` ERROR. Applying a new selector requires a new rule revision.
- Unmapped or unreadable eligible files make the full-repo concentration share UNKNOWN and publish the observed partial value. That does not PASS or FAIL the 0.60 advisory.
- M09 centrality and reach are descriptive. There is no universal PASS/FAIL rule.
- Structural admission still drops transitive depth, so the bundled boundary example evaluates direct edges only.
- Launch catalog YAML is `architecture.boundary` / `architecture.concentration` plus the E07.1 cycle and fan-out rules. Legacy Python SharedRules remain for the old pack.
- `pip-audit` exit 1 is host pip, not an Engine dependency finding.
- Host is Windows / Python 3.12.10 (`.venv-engine-next`).

view separate from traversal and reports truncation as a lower bound with
UNKNOWN completeness. The M06 external-edge ratio stays on eligible file
import edges classified by component.
