## Requirement mapping

| Requirement | Implementation |
|---|---|
| Resolve committed HEAD | `select_first_parent_series()` uses `rev-parse HEAD` via `run_readonly_git` after `resolve_containing_git_root()` |
| First-parent `--max-count=5` | `rev-list --first-parent --max-count=5 HEAD` |
| Reverse oldest→newest | Newest-first list is reversed; S1 oldest requested, S5 = HEAD |
| Five-slot model if fewer commits | Always 5 slots; older missing slots stay `insufficient_history` (not left-shifted) |
| Materialize isolated temp trees | `SnapshotWorkspace` + `materialize_commit_tree()` under `tempfile.TemporaryDirectory` |
| Read-only Git only | `ls-tree` + `cat-file blob` through `run_readonly_git` / `run_readonly_git_bytes` |
| No checkout / hooks / build / tests | Allow-list unchanged except binary reader; verbs used are rev-parse, rev-list, ls-tree, cat-file |
| Cleanup on success/failure | `SnapshotWorkspace.close()` / `__exit__` always `TemporaryDirectory.cleanup()` |
| Dirty files excluded | Extraction reads committed objects only |
| Worktree unchanged | `capture_worktree_fingerprint()` compares HEAD/index/status digests |
| Submodule / symlink safe | Gitlinks skipped; escaping/absolute symlinks skipped; documented in module |

`git archive` was not added. It applies `export-ignore` and would fail “tree bytes match each SHA”.
