Title: `E08.3: Complete evidence-backed maintainability prioritization`

Body:

Emit unified M22 Engineering Hotspot records ranked only by component complexity × pinned-window changed lines, then stable component ID. Centrality, reach, ownership and active findings are context_only and cannot change rank. Missing or partial ranking inputs stay UNKNOWN/unranked while known static complexity evidence is retained.
