## PR text for `release/engine-next`

Title: `E06.2: Implement resolved supply-chain and vulnerability matching`

Body:

Resolve manifest declarations against pinned local lock snapshots and match exact versions to a pinned offline OSV (`osv.dev`) feed. M12 coverage is fully resolved eligible declaration IDs over eligible IDs in the same manifest/workspace/environment scope; occurrences and transitive packages cannot inflate that ratio. Missing or stale feed makes M13 matching UNKNOWN and never reports zero CVEs as clean. `security.known_vulnerability` is bundled YAML; withdrawn advisories, alias groups and prerelease SEMVER boundaries are tested. No live lookup and no package install during canonical evaluation.
