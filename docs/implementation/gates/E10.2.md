## Known limitations

- Static blast radius tracks possible static reverse dependency reach, not runtime execution probability or measured test coverage.
- Change concerns join is context-only by default and does not drive outcome verdicts unless explicitly ratified in driver manifests.
- Multi-dimensional differences without controlled paired reruns evaluate to `mixed` attribution and never guess dominant cause.

**Title:** `E10.2: Calculate graph delta, impact and change verdicts`

```text
Implement M29 graph delta and bounded reverse-dependency blast radius, M30 thresholded
outcome movement across all four public outcomes, and M31 multi-dimensional cause attribution.

Key capabilities:
- Bounded reverse-dependency BFS traversal (depth 4..32, node/edge budgets, cycle/diamond de-duplication)
- Static blast radius reporting affected components, test associations (E08.2), boundary spread, and crossed boundary ordered pairs
- M29 contextual change-concern join over churn (M24 / E08.3) and centrality (M09 / E07.2) with exact nearest-rank p90 predicates
- M30 outcome movement classification using versioned launch driver manifest (launch-ratification-v1.yaml)
- Precedence: INSUFFICIENT > MIXED > DETERIORATED > IMPROVED > STABLE with strict epsilon thresholds
- Surviving known violations preserved even under incomplete coverage
- Empty outcome and disabled-all scope evaluate to NOT_APPLICABLE (never healthy/Stable)
- M31 cause attribution across source, feed, and configuration dimensions with feed-driven CVE deterioration protections
- Fully integrated with ScanComparisonService.compare_results and compare_with_lifecycle
```
