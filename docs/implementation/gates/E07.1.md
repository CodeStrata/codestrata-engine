## PR text for `release/engine-next`

```text
E07.1: Normalize structural edges and cycle metrics

Admit imports, depends_on, implements, exposes_API and uses_dependency
at supported confidence/depth with stable relationship IDs. Call edges
stay callable-to-callable and reliable-only; cross-repository and
runtime topology are dropped. M05 reports module SCC cycles (size>1
plus self-loops) and M06 reports fan_in/out plus the file-import
external-edge ratio. YAML launch rules architecture.cycles (FAIL if
any cycle; incomplete negative cannot PASS) and architecture.fan-out
(threshold 10, medium, configurable) run through the E03.1/E03.2/E03.3
catalog. Unresolved edges and partial source roots stay UNKNOWN rather
than a clean PASS.

Does not implement E07.2/E07.3 or migrate the remaining Python
architecture SharedRules.
```
