## Known limitations

- `compare` requires two `AnalysisResult` JSON reports. A partial or incompatible file exits 1. It does not compute outcome movement; that stays with later comparison stories.
- Custom-rule commands are absent from `codestrata rules`. Invoking them is Typer's unknown-command failure, plus the contract message in `reject_custom_rule_command`.
- Assess skips the interactive collection prompt (`stdin_interactive=False`). Telemetry remains off until a separate consent command. `--telemetry-allow` still cannot invent consent.
- `pip-audit` exit 1 is the host installer, not an Engine dependency change.
