## Known limitations

- `LocalArtifactEvidenceService` reads structured JSON and YAML artifacts produced by CodeStrata runs. Arbitrary binary files or external SQLite databases are deliberately excluded.
- Single-page query budget is capped at 500 items maximum to enforce bounded memory consumption on local clients.

### Summary
Implements P40 - E12.1: Serve bounded local evidence queries from artifacts.
Provides a pure, zero-database FastMCP server (`create_artifact_mcp_server`) exposing deterministic read-only queries across 9 evidence domains directly from local filesystem run artifacts.

### Key Changes
- **LocalArtifactEvidenceService:** Pure file-based reader (`LocalArtifactEvidenceService`) for repositories, snapshots, components, findings, metrics, dependencies, changes, evidence, and lineage.
- **Security & Scoping:** Strict path traversal checks (`..`), system directory prohibitions, file extension gating (`.json`, `.jsonl`, `.txt`, `.sarif`), and schema version validation.
- **Budgeting & Pagination:** Enforces query limits (1-500) and character budgeting with truncation indicators without breaking JSON output validity.
- **Zero-Database & Read-Only:** Zero SQLite/SQL connections. Assessment execution, rule activation, shell execution, hosted telemetry, portfolio cross-repo queries, and GraphRAG/answering tools are strictly excluded.
- **No-Consent Utility:** Operates completely offline without requiring collection consent.
- **Documentation:** Updated `docs/mcp/tools.md` and `docs/mcp/security.md`.
