# E02.3 — Deprecated Community surfaces and leftover snapshot export

Package revision `ENGINE-2026-09-15-R1`. Community Engine execution is local
YAML assessment against file artifacts. The commands and helpers below are
either removed from Community or retained only as compatibility projections.

## Removed from Community execution

| Surface | Former path | Community behavior |
|---|---|---|
| Hosted Platform ingest | `publish_assessment_to_platform`, `publish_artifacts_to_platform`, `platform_client_from_settings` | Always offline / `status=removed`. No Platform HTTP from canonical runtime. |
| Community Cloud report upload | `codestrata report publish`, `publish_local_assessment` | Deprecated. Exit 2. Local HTML is unchanged. |
| Portfolio / EIR lifecycle | `promote_intelligence_run`, `codestrata report publish --type eir`, `publish_local_eir` | Refuses. Existing `intelligence/` trees are not migrated or deleted. |
| Customer rule authoring | CLI / MCP write-rule tools | Not present. `codestrata rules` and MCP shared-rule tools are list/inspect/explain only. |
| Strategic / enterprise agents | Platform `enterprise_*` MCP/CLI extensions | Not constructed by Community composition. Local Agent Framework remains repository-scoped. |

## Compatibility projections (safe, not active)

- `RestPlatformClient` and `MockPlatformClient` remain importable for
  outside-Engine hosts and tests. Community `platform_client_from_settings`
  never constructs `RestPlatformClient`.
- Portfolio identity helpers (`resolve_portfolio_artifact_id`) remain
  read-only. They do not promote EIR folders.
- Local `codestrata report validate` / `codestrata open` remain supported.

## Legacy SQLite snapshot export

Community runtime never imports the SQLite adapter or exporter.

Maintainer helper (separate process only):

```bash
python -m codestrata.infrastructure.knowledge_store.sqlite.export \
  --sqlite .codestrata/knowledge/knowledge.sqlite \
  --output /tmp/codestrata-sqlite-export
```

The helper is read-only against the SQLite file, refuses to overwrite an
existing destination, and does not migrate FileKnowledgeStore data. Old
`knowledge.sqlite` files and prior installs stay untouched.

## Outside-Engine consumers (read-only)

Platform still imports `codestrata.infrastructure.knowledge_store` and
`RestPlatformClient`. Those contracts are recorded as breaking for hosts that
imported `SqliteKnowledgeStore` from the production package. This story does
not edit `platform/` or `workers/`.
